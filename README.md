# Tankbuch

Persönliches Tankbuch als Web-App: Tankvorgänge eintragen, Verbrauch (l/100 km), Kosten und Spritpreis-Entwicklung mit Monats- und Jahresstatistik.

**App öffnen:** https://tr4shcookey.github.io/tankbuch/

- Läuft komplett im Browser, auch offline nach dem ersten Öffnen.
- Alle Tankdaten bleiben auf dem eigenen Gerät (Browser-Speicher). In diesem Repository liegen **keine** persönlichen Daten.
- Abgleich zwischen iPhone und Mac über eine Sicherungsdatei in iCloud Drive (Einstellungen → Sicherung speichern / laden).

Diagramme: [Chart.js](https://www.chartjs.org/) 4.4.1 (MIT-Lizenz, siehe `vendor/chart.js-LICENSE.md`).
